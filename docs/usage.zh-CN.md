# 消息模拟发送器使用说明

## 启动工具

1. 双击项目根目录下的 `start.bat`。
2. 等待后端和前端窗口启动完成。
3. 浏览器访问 `http://localhost:5173`。

后端默认地址为 `http://localhost:3001`，前端默认地址为 `http://localhost:5173`。

## 配置服务

1. 在服务首页点击“新建服务”或进入已有服务配置。
2. 选择协议：HTTP、MQTT、WebSocket、TCP 或 OPC UA。
3. 设置协议端口、路径、主题、节点等协议参数。
4. 编辑消息模板和随机参数。
5. 返回服务首页，点击单个服务的“启动”，或点击“全部启动”。

## 处理端口占用

启动服务时，如果端口已被占用，页面会弹出提示并显示端口号和占用进程 PID。

- 点击“确定”：工具会关闭占用这些端口的进程，并自动重新启动服务。
- 点击“取消”：工具不会关闭进程，服务保持未启动状态。

请在确认前检查 PID，避免关闭正在使用的重要程序。

## 保存和加载配置

- 点击“保存配置文件”可将当前服务配置保存到指定路径。
- 点击“加载配置文件”可从指定路径恢复服务配置。
- 默认配置路径为 `save/config.json`。

## 协议连接

连接方式会优先显示本机局域网 IPv4 地址，例如 `192.168.x.x`，方便同一局域网内的其他设备直接配置连接。

- HTTP：使用页面显示的 `GET` 地址请求消息。
- MQTT：连接页面显示的 Broker 地址，并订阅配置的 Topic。
- WebSocket：连接页面显示的 WebSocket URL。
- TCP：连接页面显示的 TCP 地址。
- OPC UA：连接页面显示的 Endpoint，并读取配置的 Node ID。
