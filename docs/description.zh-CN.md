# 消息模拟发送器描述

消息模拟发送器是一个本地运行的多协议消息服务工具，用于快速模拟 HTTP、MQTT、WebSocket、TCP 和 OPC UA 数据发送场景。用户可以为每个服务配置独立的协议、监听端口、消息模板、随机参数和发送间隔，并在同一个 Web 界面中启动、停止、复制和管理多个模拟服务。

工具适合联调、设备数据模拟、接口验收和演示环境。它会根据配置生成当前消息快照，并按照所选协议对外提供或推送该消息：

- HTTP：客户端使用配置的 GET、POST、PUT、PATCH 或 DELETE 方法请求指定路径时返回当前消息。
- MQTT：内置 Broker 按主题定时发布消息。
- WebSocket：客户端连接后按间隔推送消息。
- TCP：客户端连接后发送消息文本。
- OPC UA：在指定节点上维护并刷新模拟值。

启动协议服务时，系统会先检查目标端口是否已被其他进程占用。如果发现端口冲突，页面会弹出确认提示，列出占用端口和进程 PID。用户确认后，系统会自动关闭这些占用端口的进程，然后重新启动对应的协议服务；用户取消时不会关闭任何进程。
